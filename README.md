# 🧮 Smart Calculator

A modern and responsive calculator built using **HTML**, **CSS**, and **JavaScript**. This project performs basic arithmetic operations while providing a clean user interface, smooth animations, and Local Storage support for a better user experience.

---

## 🚀 Features

- ✅ Addition, Subtraction, Multiplication, and Division
- ✅ Percentage Calculations
- ✅ Clear (C) Functionality
- ✅ Backspace/Delete (⌫) Functionality
- ✅ Decimal Number Support
- ✅ Responsive Design
- ✅ Modern Dark-Themed UI
- ✅ Hover & Click Animations
- ✅ Local Storage Support

## ⚙️ How It Works

### Number Input

Users can enter numbers using the calculator buttons.

### Arithmetic Operations

Supports:

```plaintext
+
-
*
/
%
```

### Clear Function

```plaintext
C
```

Removes the entire expression from the display.

### Backspace Function

```plaintext
⌫
```

Deletes the last entered character.

### Calculate Result

```plaintext
=
```

Evaluates the mathematical expression and displays the result.

---

## 💾 Local Storage Support

The calculator automatically saves the current display value using the browser's Local Storage.

Example:

```plaintext
125 + 75
```

If the page is refreshed, the expression remains available.

This feature was implemented using:

```javascript
localStorage.setItem()
localStorage.getItem()
```
